H3 → OE Object Mapping Editor

Standalone editor for src/lib/h3-import/h3-object-mapping.json — the master table that decides what each H3 object becomes when importing a .h3m map. Load your Core.zip (to validate OE sids for real) and the mapping JSON below, edit rows in the table, then download the result and replace the file in the repo. Not part of TSE itself — this file only reads/writes local files you choose, nothing is sent anywhere.

How to use it:

Open the file directly in a browser (double-click, or file:// works fine), load your Core.zip and src/lib/h3-import/h3-object-mapping.json via the two file pickers, edit away, then hit "Download edited JSON" and move the downloaded file over the real one in the repo.

What it does:

- Parses Core.zip's real object catalog (same 9 category files and interactable rules builder.ts uses) to give live green/red sid validation as you type or edit — the same check I did by hand for Tavern.
- Full first-class fields (sid with validation, kind, reason, role, etc.) for omit/emit/scenery rows — the common case of turning an omitted object into a real mapping.
- A JSON textarea for the rarer nested shapes (dispatch, scenery-dispatch, scenery-dispatch-subtype) rather than a fully dynamic editor, to keep it genuinely simple.
- Search box + outcome filter, and a running summary (row count, field errors, missing sids).
