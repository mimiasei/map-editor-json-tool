## Что такое счётчики

Счётчики — это целочисленные переменные сценария. Они объявляются на вкладке **Счётчики** с SID и начальным значением и сохраняются на протяжении всей жизни карты.

Это основной инструмент для отслеживания хода заданий, числа убийств, ресурсных рубежей и ветвления логики.

## Объявление счётчика

Добавьте счётчик на вкладке «Счётчики». Задайте:
- `sid` — уникальный строковый идентификатор, например `dragons_killed`
- `value` — начальное значение, почти всегда `0`

Используйте описательные SID — вы будете ссылаться на них по имени во всей логике триггеров.

> **Note:** Счётчики не отображаются в редакторе карт. Они существуют только в JSON и невидимы, пока карта не запущена в игре.

## Изменение счётчиков

Значения счётчиков меняют четыре действия:

- `CounterSet` — устанавливает определённое значение
- `CounterPlus` — увеличивает на величину
- `CounterMinus` — уменьшает на величину
- `CounterSetRandom` — устанавливает случайное значение между минимумом и максимумом

## Проверка счётчиков

Используйте условие `Counter`, чтобы сравнить значение счётчика:

- `quest_stage = 2` — ровно на этапе 2
- `dragons_killed >= 5` — убито не менее 5
- `quest_stage != 0` — задание началось

## Приём «этап задания»

Самый распространённый приём со счётчиками — **счётчик этапа задания**:

1. Добавьте счётчик `quest_main_stage` с начальным значением `0`
2. По завершении каждого этапа выполняйте `CounterSet quest_main_stage → N`
3. Ограничьте следующий триггер условием `Counter: quest_main_stage = N`

Так этапы срабатывают по порядку и только один раз.

## Приём «подсчёт убийств»

Чтобы потребовать убить N каких-либо существ:

1. Добавьте счётчик `kills_count` с начальным значением `0`
2. Добавьте триггер `UnitKill` с действием `CounterPlus kills_count 1` — установите `repeat: true`
3. Добавьте второй триггер: когда `Counter: kills_count >= N`, запускайте завершение

Можно также использовать встроенное дополнительное поле Counter у условия `UnitKill`, чтобы задать порог напрямую, без отдельного счётчика.

## Случайное ветвление

Используйте `CounterSetRandom` для случайного ветвления:

1. Установите счётчик `branch` в случайное значение от 1 до 3
2. Добавьте три отдельных триггера, проверяющих `Counter: branch = 1`, `= 2`, `= 3`
3. Каждая ветка запускает свой диалог или исход

Подходит для фоновых событий и разнообразия случайных встреч.
