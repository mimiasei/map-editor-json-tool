## Редактор карт не отражает изменения JSON

Это самое важное, что нужно понять: **изменения, которые вы вносите в этом редакторе — логика заданий, счётчики, триггеры — невидимы в редакторе карт HoMM:OE.** Редактор карт показывает только визуальный слой (ландшафт, объекты, героев на карте).

Ваши изменения в JSON читает **игровой движок во время работы**, а не редактор карт.

> **Warning:** Не открывайте сохранённый файл карты в редакторе карт HoMM:OE в надежде увидеть логику заданий. Вы увидите только визуальный слой. Игра корректно читает JSON во время работы.

## Порядок проверки

Правильный порядок проверки логики заданий:

1. Внесите изменения в этом редакторе
2. Выполните **Сохранить как** (или Экспорт), чтобы получить обновлённый файл JSON
3. Замените JSON сценария в файле карты (или положите его туда, где его ожидает игра)
4. Загрузите карту в HoMM:OE
5. Проверьте нужный сценарий в игре
6. Повторяйте

## Где в карте находится JSON сценария

Файл карты `.homm` — это ZIP. Распакуйте его и найдите `scenario.json` (или файл с похожим именем) в корне или в папке `DB/`. Замените его обновлённым JSON, затем снова упакуйте архив в ZIP.

> **Note:** Перед заменой файлов сохраните резервную копию исходной карты.

## Сначала проверьте валидатором

Перед проверкой в игре нажмите **Проверить** на панели инструментов. Валидатор находит:

- Отсутствующие токены локализации
- Ссылки на счётчики, не совпадающие с объявленными счётчиками
- Ссылки на SID заданий и подзаданий, которых не существует
- Пустые обязательные параметры

Исправьте все ошибки перед проверкой в игре. Предупреждения носят информационный характер — игра всё равно может работать правильно.

## Советы для быстрых итераций

- Используйте `CounterSet`, чтобы быстро перемотать состояние задания в тестовом триггере (например, установите `quest_stage` в 5 на ходу 1, чтобы проверить логику поздней игры)
- Используйте `SpawnHero`, чтобы поставить конкретного героя для проверки условий, требующих наличия героя
- Используйте `RevealFogOfWar` в начале карты с большим радиусом, чтобы видеть всё во время проверки
