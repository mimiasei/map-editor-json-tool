## Обзор

Диалоги в HoMM:OE определяются отдельными файлами JSON в `DB/dialogs/dialogs/`. У каждого диалога уникальный ID, и он содержит один или несколько слайдов (текст и сведения о говорящем).

Действие `Dialog` проигрывает диалог по его ID. Действие `RandomDialog` проигрывает один из нескольких диалогов случайным образом.

## Создание диалога

Используйте **Редактор диалогов** (доступен из панели «Диалоги» или через ярлык «Править диалог →» в действии Dialog). У каждого слайда диалога есть SID локализации текста, необязательный говорящий и необязательные сведения о портрете.

SID текста всех слайдов нужно добавить в локализацию вашей карты через диалог **Локализация**.

## Использование действия Dialog

Добавьте действие `Dialog` в любой триггер. Задайте **ключ диалога**, точно совпадающий с SID созданного вами диалога.

Диалог запускается, когда выполнены условия триггера.

> **Note:** Диалог и все его токены локализации должны входить в ZIP вашей карты. Используйте **Экспорт ZIP**, чтобы собрать всё вместе.

## Диалоги при взаимодействии с объектами

Распространённый приём — показать диалог, когда игрок взаимодействует с объектом карты:

1. Добавьте триггер в подзадание
2. Добавьте условие `ObjectInteractionBefore` — укажите Entity SID вашего объекта карты
3. Добавьте действие `Dialog`

Диалог запускается до стандартного взаимодействия с объектом (подбор сокровища, бой и т. п.).

## Включение диалогов в ZIP карты

Игра читает диалоги из папки `DB/dialogs/` ZIP карты. Редактор управляет этим за вас: при **Экспорте ZIP** все диалоги, добавленные через Редактор диалогов, включаются автоматически.

Не кладите файлы диалогов в ZIP вручную — структуру обеспечивает редактор.

> **Warning:** Если вы сослались на ID диалога, которого нет в ZIP, игра молча пропустит его без ошибки. Всегда проверяйте триггеры диалогов в игре.
