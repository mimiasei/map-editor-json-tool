## Редактор мапи не відображає змін JSON

Це найважливіше, що слід зрозуміти: **зміни, які ви робите в цьому редакторі — логіка завдань, лічильники, тригери — невидимі в редакторі мапи HoMM:OE.** Редактор мапи показує лише візуальний шар (ландшафт, об'єкти, героїв на мапі).

Ваші зміни JSON зчитує **ігровий рушій під час роботи**, а не редактор мапи.

> **Warning:** Не відкривайте збережений файл мапи в редакторі мапи HoMM:OE, сподіваючись побачити логіку завдань. Ви побачите лише візуальний шар. Гра правильно читає JSON під час роботи.

## Порядок перевірки

Правильний порядок перевірки логіки завдань:

1. Внесіть зміни в цьому редакторі
2. **Зберегти як** (або експортуйте), щоб отримати оновлений файл JSON
3. Замініть JSON сценарію у вашому файлі мапи (або помістіть його туди, де його очікує гра)
4. Завантажте мапу в HoMM:OE
5. Перевірте відповідний сценарій у грі
6. Повторюйте

## Пошук JSON сценарію в мапі

Файл мапи `.homm` — це ZIP. Розпакуйте його й знайдіть `scenario.json` (або файл зі схожою назвою) у корені чи папці `DB/`. Замініть його своїм оновленим JSON, а тоді знову запакуйте архів.

> **Note:** Збережіть резервну копію оригінальної мапи перед заміною файлів.

## Спершу скористайтеся перевіркою

Перед перевіркою в грі натисніть **Перевірити** на панелі інструментів. Валідатор виявляє:

- Відсутні токени локалізації
- Посилання на лічильники, що не відповідають оголошеним лічильникам
- Посилання на SID завдань/підзавдань, яких не існує
- Порожні обов'язкові параметри

Виправте всі помилки перед перевіркою. Попередження — інформаційні: гра все одно може працювати правильно.

## Поради для швидких ітерацій

- Використовуйте `CounterSet`, щоб прискорено перемотати стан завдання в тестовому тригері (напр., задайте `quest_stage` значення 5 на ході 1, щоб перевірити логіку пізньої гри)
- Використовуйте `SpawnHero`, щоб розмістити конкретного героя для перевірки умов, яким потрібен існуючий герой
- Використовуйте `RevealFogOfWar` на початку мапи з великим радіусом, щоб бачити все під час перевірки
